# Blood Bank Management System

A full-stack Blood Bank Management System developed using HTML, CSS, JavaScript, Node.js, and MongoDB.

## Features

* Donor Registration
* Blood Request Management
* Appointment Scheduling
* Blood Donation Camp Management
* Certificate Generation
* User Authentication
* Admin Dashboard

## Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* MongoDB

## Project Objective

The system helps manage blood donation activities efficiently by connecting donors, recipients, and administrators through a user-friendly web platform.
